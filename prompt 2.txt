3. tokens

* id

* status
* created_at

TOKEN GENERATION:

* Generate a unique, sequential token number for each service queue and business day.
* Prevent duplicate token numbers using database constraints and transactions.
* Assign the initial status "Waiting".
* Save all tokens in MySQL.
* Display the generated token number to the customer.
* Calculate the customer's queue position from the active queue.
* Estimate waiting time using the number of customers ahead and the configured average service duration.

BACKEND REQUIREMENTS:

* Create PHP APIs for generating tokens, retrieving queue information, and checking token status.
* Validate and sanitize all incoming data.
* Use PDO prepared statements.
* Use database transactions for safe token generation.
* Handle errors and duplicate submissions correctly.
* Do not store unnecessary personal information.
* Never expose database credentials in frontend JavaScript.
